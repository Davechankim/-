# 백라인 생태계 — 음악장비(기타) 플랫폼 투자자 소개 사이트

BEST 생태계(동네 마트)와 같은 사업 방향·가치관을 음악장비 분야로 옮긴 자매 사이트입니다.
"사람을 잇는 공통 기반을 먼저 세우고, 서비스는 그 위에 올라탄다", "연결하는 플랫폼은 편들지 않는다",
"AI는 승인 뒤에만 실행한다", "끝까지 격리한다"는 원칙은 그대로이고, 역(서비스)만 바뀌었습니다.

| BEST 생태계 | 백라인 생태계 |
|---|---|
| 베스트마트 온라인몰 · 베스트마켓 | 검증 중고장터 (통합 검색 · 위탁 등록 · 검수 보증 · 간편결제) |
| — | 출장·보증 리페어 (인증 리페어맨 · 출장 · 수리 보증 · 장비 이력부) |
| — | 멤버십 라운지 (무료 이용 가능, 라운지 · 무료 출장 리페어 · 수수료 할인은 선택) |
| 베스트마켓 운영허브 | 파트너 허브 (샵·공방 간 위탁 · 부품 공동구매 · 밀린 작업 의뢰) |
| ERP · 메신저 · ARGOS | 샵 운영 도구 · 메신저 · 로디(AI 에이전트) |
| 철도 · 레일 · 역 | 무대 · 백라인 · 역 (노선도 비유는 유지) |

구현 가능성 검증(채널별 API·약관, 결제 규제, 보증의 보험업법 쟁점, 문구 수정 제안)은 [FEASIBILITY.md](FEASIBILITY.md)에 있습니다.

## 실행

빌드 도구가 없습니다. 단일 파일이라 `backline/index.html`을 브라우저에서 바로 열면 됩니다.
GitHub Pages를 켜면 `https://davechankim.github.io/-/backline/`에서 열립니다.

```bash
python3 -m http.server 8080   # 저장소 루트에서 실행 후 http://localhost:8080/backline/
```

## 구조

단일 파일 `index.html` 안에 CSS → 본문 → JS 순서로 들어 있습니다.

| 섹션 id | 제목 | 내용 |
|---|---|---|
| `hero` | 시작 | "장비를 팔지 않습니다. 사람을 잇는 무대를 세웁니다." + 참여자 신호선 |
| `why` | 왜 지금 | 매물을 찾는 비용 ↓ / 검증·연결의 가치 ↑ 개념도, 세 원칙 |
| `map` | 생태계 | 노선도: 공통 기반 · 검증 중고장터 · 출장·보증 리페어 · 파트너 허브 · 로디 · 샵 운영 도구 · 메신저 · 다음 서비스 |
| `services` | 서비스 | 한 계정의 네 역할(판매자·리페어맨·구매자·위탁 접수처) + 타일 4 |
| `market` | 장터 | 통합 검색 ↔ 위탁 등록 부채꼴 그림, 검수·보증, 결제 수단 |
| `repair` | 리페어 | 출장 리페어 · 보증 리페어맨 · 공연 전 점검, 장비 이력부 카드 |
| `tools` | 업무 도구 | 로디 채팅 시연(출장 일정 조회 → 배정 요청 → 리페어맨 수락) |
| `trust` | 원칙 | 중립 규칙 9, 끊기지 않는 거래 7단계, 개발 검수 목표 4 |
| `model` | 수익 | 거래 서비스 비용 · 멤버십 · 파트너 도구/현장 지원, "커질수록 각자의 몫도" |
| `join` | 참여 | 입문 연주자 ~ 악기점까지 4단계 시작 기능 |
| `roadmap` | 로드맵 | 공통 기반 → 장터 → 리페어 → 파트너 허브 → 멤버십·신규 서비스 |
| `contact` | 문의 | 마무리 선언 + 연락처 자리 |
| `detail` | 상세 설계 | 거래 흐름 A·B·C, 공통/분리 원칙, 판단 기준 8, 하지 않는 것, 예상 질문 |

## 이름 후보

사이트의 '백라인(BACKLINE)'은 가칭입니다. 확정 전에 특허정보검색(KIPRIS) 상표 검색(9·35·36·37·42류)과 도메인·앱스토어·SNS 계정 확보를 먼저 확인하세요.

### 토스처럼 한 단어 (추천 순)

토스가 되는 이유를 공식으로 쓰면 이렇습니다. ① 누구나 아는 일상 단어 ② 핵심 행동을 가리키는 동사 느낌 ③ 1~3음절 ④ 하위 서비스 이름으로 바로 확장 ⑤ 브랜드가 곧 슬로건.

| 후보 | 한 줄 | 왜 사업 방향이 담기나 | 하위 이름 | 주의 |
|---|---|---|---|---|
| **잼 JAM** (추천) | 같이 치면, 잼. | 잼 세션은 악보도 자격도 없이 모여서 바로 함께 연주하는 자리. "사람을 먼저 모은다 · 조건 없이 올라탄다 · 같은 무대를 공유한다"가 한 글자에 들어감. 한국어 '잼(재미)'의 뜻이 덤 | 잼 장터 · 잼 리페어 · 잼 라운지 · 잼 허브 · AI 로디 | 식품 '잼'과 겹침(당근마켓처럼 흔한 명사도 브랜드가 됨). 음악 소셜 서비스 'Jam United', 종료된 '잼라이브' 등 선행 사용. 검색은 '잼 기타'로 |
| **플러그 PLUG** | 꽂으면, 무대. | 기타를 앰프에 꽂는 그 동작이 곧 '연결'. 연주자·리페어맨·샵이 같은 백라인에 꽂힌다. '꽂혔다(빠졌다)'는 속어가 덤 | 플러그 장터 · 플러그 리페어 · 플러그 라운지 · 플러그 허브 | 3음절. KEPCO PLUG(전기차 충전)·플러그링크·N2 PLUG(증권) 등 다른 업종 선행 사용 |
| **튠 TUNE** | 맞추고, 손보고, 조율한다. | 튜닝은 악기를 맞추는 일이자 사람 사이를 '조율'하는 일. 리페어·검수·중립 운영을 한 단어로 | 튠 장터 · 튠 리페어 · 튠 라운지 | '튜닝(자동차)' 연상. 미국 마케팅 회사 TUNE, 튜너 앱 다수 |
| 앰프 AMP | 키운다. | 플랫폼이 커질수록 각자의 몫이 커진다 = 증폭. 백라인의 핵심 공용 장비 | 앰프 장터 · 앰프 리페어 | 'AMP'는 세계적으로 흔한 상표 |
| 코드 CHORD | 따로 울리던 음이 하나의 화음으로. | 화음(함께 울림) + 코드(케이블, 연결)의 이중 의미 | 코드 장터 · 코드 리페어 | 'code'와 겹쳐 검색 식별이 어려움 |

한글 한 단어를 원하면 **어울림**(사람이 어울리다 + 소리가 어울리다)과 **화음**이 같은 공식을 만족합니다. 다만 둘 다 흔한 말이라 독점이 어렵습니다.

### 비유형 후보 (참고)

| 후보 | 뜻 | 왜 맞는가 | 주의 |
|---|---|---|---|
| 백라인 BACKLINE | 무대 뒤 공용 장비. 출연자는 자기 악기만 들고 와 같은 백라인으로 연주 | '공통 기반' 비유 그대로. 현장 용어라 연주자에게 즉시 통함 | 비연주자에게 설명 필요. 렌탈 업계의 일반명사 |

| 프렛라인 · 트러스 · 세션 | 프렛이 역처럼 늘어선 선 · 넥을 지탱하는 보이지 않는 로드 · 함께 연주하는 자리 | 노선도·기반·커뮤니티 비유 | 조어 설명 필요 · 딱딱함 · 일반어 |

AI 에이전트 이름 '로디(ROADIE)'는 어떤 이름을 고르더라도 함께 쓸 수 있습니다(무대 뒤에서 장비를 나르고, 점검하고, 승인된 것만 건네는 사람).

## 내용 수정

- **연락처**: `id="contactValue"` 문단의 텍스트를 실제 연락처로 바꿉니다.
- **브랜드명**: 상단바(`.brand-text`와 `.brand`의 aria-label), `<title>`, `og:title`, 히어로 문장의 "백라인", 푸터에서 바꿉니다. 본문에서 `백라인`을 검색하면 모두 찾을 수 있습니다.
- **노선도 역 설명**: `<script>` 안 `STATIONS` 객체. 역 자체(위치·이름)는 `<svg class="metro">` 안에 있습니다.
- **채팅 시연 대사**: `playChat()`, `dataCard()`, `approveCard()`.
- **장터 채널 목록**: `<figure class="fan">`의 SVG 노드와 그 아래 `.fan-list`(휴대전화용 목록) 두 곳을 같이 고칩니다.
- **결제 수단**: `.pay` 안의 pill.
- **속도 목표 수치**: `ul.targets`.

## 아티팩트(claude.ai)로 올리기

아티팩트는 자체 문서 뼈대로 감싸므로 바깥 껍데기만 떼어 올립니다. 저장소 루트에서:

```bash
awk '!/^(<!DOCTYPE html>|<html lang="ko">|<head>|<meta charset="UTF-8">|<meta name="viewport"|<\/head>|<body>|<\/body>|<\/html>)/' backline/index.html > /tmp/backline-artifact.html
```

서비스 구성·업무 흐름·수치는 설계 목표이며 구현 완료나 검증된 성과가 아닙니다. 채팅 시연과 장비 이력부는 가상 데이터입니다.
통앤통·뮬·당근마켓·번개장터·인스타그램·네이버 스마트스토어·네이버페이·카카오페이·토스·헤이딜러·엔카는 각 사의 상표이며 제휴 관계를 뜻하지 않습니다.
다른 채널의 매물을 검색하거나 자동 등록하는 기능은 채널별 약관·API 허용 범위에 달려 있습니다. 검증 결과와 문구 수정 제안은 [FEASIBILITY.md](FEASIBILITY.md) 11장을 보세요.
