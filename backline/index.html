  2. 위탁 등록사진·모델·희망가를 한 번 입력합니다. 채널별 양식에 맞춘 판매글을 만들어 동시에 올리고, 팔리면 모든 채널에서 한 번에 내립니다.

연결하는 플랫폼,
편들지 않는 운영사.

연결하는 플랫폼과 매물을 사고파는 상인은 다른 사업입니다. 운영사가 검수·보증·결제에 직접 관여하기 때문에 중립 기준을 더 엄격하게 두고, 약관이 아니라 제품 구조로 지킵니다.

  1. 판매자의 선택권가격·판매 채널·거래 방식·거래 상대는 판매자가 정합니다. 시세는 참고로만 보여 줍니다.
  2. 검수자 독립검수자는 그 거래의 판매자·구매자·중개 수익과 이해관계가 없어야 합니다. 검수 항목·등급 기준·검수자를 공개합니다.
  3. 동등 노출어느 채널에서 왔든, 운영사 매물이든, 멤버십이든 검색 순서는 같은 기준입니다. 운영사가 파는 매물은 그렇게 표시합니다.
  4. 평가는 거래한 사람만리페어맨·판매자 평가는 거래 완료자만 남기고, 운영사도 지우거나 올리지 않습니다.
  5. 비공개 자료 이용 금지샵·리페어맨의 매입가·고객·매출 데이터를 운영사의 직영 사업에 쓰지 않습니다.
  6. 권한 분리플랫폼 운영 권한과 직영 검수·직영 판매 권한을 분리합니다. 관리자라는 이유로 참여자의 대화를 상시 열람하지 않습니다.
  7. 승인 후 실행AI(로디)는 승인 전에 데이터를 바꾸지 않고, 승인 후에도 공식 업무 API로만 실행합니다.
  8. 끝까지 격리데이터베이스뿐 아니라 검색·파일·임시 저장소·대기열·백업·AI 범위까지 샵·개인별로 분리하고, 한 샵의 대량 작업이 이웃을 늦추지 않게 자원을 나눕니다.
  9. 떠날 자유장비 이력·거래 기록·평가는 본인 소유입니다. 언제든 내려받아 나갈 수 있어야, 머무는 이유가 종속이 아니라 가치가 됩니다.

장비 한 대를 팔아
버는 회사가 아닙니다.

기능 하나하나를 팔거나 매물마다 마진을 얹어 매출을 만드는 회사가 아닙니다. 특정 기능을 참여 조건으로 걸지 않고, 연결망 위에서 실제로 생긴 가치의 일부를 나눕니다.

  1. 거래 서비스 비용검수·보증·안전결제·배송. 이용한 거래에만 붙고, 사기·분쟁·반품까지 포함한 실제 비용이 줄었는지 확인합니다.
  2. 멤버십라운지, 무료 출장 리페어, 검수·위탁 수수료 할인, 우선 예약. 참여 조건이 아니라 선택지입니다. 무료로도 끝까지 쓸 수 있습니다.
  3. 파트너 도구·현장 도입 지원샵 운영 도구의 고급 기능과 위탁 대행. 첫 매물 등록부터 첫 거래까지 함께합니다. 소프트웨어 제공으로 끝나지 않는 지원이 참여를 만듭니다.

세 가지를 한꺼번에 부과하지 않고, 참여자에게 실제 가치가 생겼다고 확인된 항목부터 적용합니다. 수수료율과 수익성은 근거가 쌓인 뒤 정합니다.

플랫폼이 커질수록,
각자의 몫도 커져야 합니다.

  1. 판매자구매자가 많아질수록 더 빨리, 제값에 팝니다. 수수료는 성사된 거래에만 붙습니다.
  2. 리페어맨의뢰가 많아질수록 동선이 짧아지고 보증 비용이 내려갑니다. 평가는 거래한 사람만 남깁니다.
  3. 샵·공방위탁·부품·밀린 작업 거래가 늘수록 재고가 돌고 손이 빕니다. 간판과 가격은 그대로입니다.

노출은 동등하게, 수수료는 거래에만, 이력은 본인 소유로. 커지는 플랫폼이 개인의 몫을 줄이는 순간 생태계는 끝납니다.

사진 한 장으로
시작합니다.

가입 조건은 멤버십도, 샵 계약도 아닙니다. 기타 사진 한 장과 모델명만 등록해도 통합 검색·장비 이력부·리페어 예약을 쓸 수 있습니다. 멤버십은 그다음의 선택입니다.

  1. 입문·취미 연주자

    처음
    통합 검색, 내 장비 등록(이력부), 출장 셋업 예약
    이후
    위탁 판매, 멤버십 라운지, 단골 리페어맨

  2. 전문 연주자·강사

    처음
    긴급 출장 수리, 공연·녹음 전 점검
    이후
    정기 세팅, 장비 렌탈·레슨 연결

  3. 개인 리페어맨·소규모 공방

    처음
    인증 등록, 출장 의뢰 받기, 작업 기록
    이후
    검수 의뢰, 보증 리페어, 부품 공동구매

  4. 악기점·리페어샵·장비 판매점

    처음
    재고 게시, 위탁 접수, 고객 상담
    이후
    샵 운영 도구, 밀린 작업 의뢰, 공동구매

검수되지 않은 매물은 검수 매물처럼 보여주지 않습니다. '검수 전'과 '마지막 갱신 시각'을 표시하고, 결제 전에 판매자가 확인합니다.

크게 설계하고,
연결이 필요한 순서로 짓습니다.

한 지역의 연주자와 협력 가능한 공방·악기점에서 시작해, 하나의 생활권에서 하나의 거래 흐름을 반복해 검증합니다. 사람이 먼저, 샵은 뒤따릅니다.

  1. 공통 기반같은 계정으로 여러 서비스를 쓰되, 샵·개인별 자료는 분리됩니다. 장비 이력부·결제·권한이 여기 있습니다.
  2. 검증 장터 연결통합 검색 → 위탁 등록 → 검수·보증 → 안전결제가 한 흐름으로 이어집니다.
  3. 리페어 네트워크 연결출장 예약 → 인증 리페어맨 배정 → 수리 보증 → 이력 기록. 검수와 수리가 같은 사람, 같은 기준으로 묶입니다.
  4. 파트너 허브 연결샵·공방 간 위탁·부품·밀린 작업 거래가 소비자 거래와 구분된 채 연결됩니다.
  5. 멤버십·신규 서비스 검증라운지와 무료 출장 리페어를 열고, 렌탈·레슨·백라인 렌탈 같은 새 역을 기존 기반 위에 더합니다.

지금 기타 치는 사람의 하루
  • 거래망 같은 기타를 통앤통·뮬·당근마켓·인스타그램에 따로 올리고, 네 곳의 쪽지에 따로 답합니다. 팔리면 네 곳에서 따로 내립니다.
  • 신뢰 사진과 말만 믿고 송금합니다. 넥 상태·전장·수리 이력은 받아 보고야 압니다. 분쟁은 각자 알아서 합니다.

거래 흐름 예시 A · B · C: 연결하되 섞지 않습니다

세 서비스(장터·리페어·파트너 허브)를 오가는 거래는 하나의 로그인과 공통 장비 기준 위에서 이어집니다. 다만 소비자 거래와 샵 간 거래, 판매자와 위탁 접수처의 기록은 각각 남깁니다. 구현 목표를 보여 주는 예시입니다.

A. 위탁 등록 → 검수 → 모든 채널 게시 → 안전결제

  1. 판매자가 사진·모델·희망가 등록
  2. 로디가 시세 참고·채널별 초안 제안
  3. 인증 리페어맨 검수·검수서 발급
  4. 판매자 승인
  5. 모든 채널 동시 게시
  6. 구매자 안전결제 (카드 할부·간편결제)
  7. 수령 확인·정산
  8. 이력부 소유 이전
  • 검수자는 그 매물의 판매자·구매자가 아니어야 합니다. 같은 사람이 리페어맨이자 판매자일 수 있지만, 자기 매물은 자기가 검수하지 못합니다.
  • 다른 채널에서 성사된 거래도 판매자가 알리면 모든 채널에서 글을 내리고 이력을 남깁니다. 강제하지 않습니다.

B. 출장 리페어 → 보증

  1. 고객 예약 (증상·사진)
  2. 로디가 동선 맞는 인증 리페어맨 제안
  3. 리페어맨 수락
  4. 방문·작업 기록 (사진·측정값)
  5. 결제
  6. 보증 기간 등록
  7. 이력부 기록
  • 수리비는 리페어맨이 정하고, 플랫폼은 참고 범위만 보여 줍니다.
  • 보증 기간 안의 재발은 공개된 기준으로 재수리·환불합니다. 분쟁 시 작업 기록이 근거입니다.

C. 샵이 위탁 접수처로 참여

  1. 개인이 샵에 기타를 맡김
  2. 샵이 검수·보관
  3. 장터·모든 채널 게시
  4. 판매·안전결제
  5. 샵이 전달
  6. 정산 (판매자·샵·플랫폼)
  • 판매자는 개인, 샵은 보관·전달 대행입니다. 기타가 샵에 있다고 샵의 매입·매출로 기록하지 않습니다. 대행 비용은 별도 약정과 정산 규칙으로 연결합니다.
  • 밀린 작업은 파트너 허브에서 다른 공방·인증 리페어맨에게 의뢰할 수 있고, 고객에게는 누가 작업했는지 알립니다.
공통으로 쓰는 것 · 절대 섞지 않는 것

공통으로 쓰는 것

  • 하나의 로그인과 본인 확인
  • 장비 품목 기준(브랜드·모델·연식·시리얼 규칙)과 검수 항목
  • 메시징 기술, 업무카드, 승인 처리 규칙
  • 파일 업로드·미리보기·공유 기술
  • 결제·정산 기술, 검색·분석 기술

절대 섞지 않는 것

  • 서비스 이용 권한, 샵·개인 소속, 관리자 권한
  • 판매자별 가격, 비공개 매입가, 재고 소유자
  • 샵 내부 대화 · 샵 간 거래 · 고객 상담
  • 파일 열람 권한, 외부 공유 허용 범위, 증빙의 소속
  • AI가 접근·실행할 수 있는 범위
생태계가 만들어지고 있는지 판단하는 기준
  1. 연주자가 다시 사용하는가
  2. 문의가 실제 거래로 이어지는가
  3. 매물과 장비 이력이 계속 갱신되는가
  4. 사기·분쟁·반품이 줄었는가
  5. 리페어 재의뢰율과 보증 청구율은 어떤가
  6. 샵이 먼저 참여를 요청하는가
  7. 새 서비스를 더했을 때 재등록·재입력·재전송이 줄었는가
  8. 그 과정에서도 속도와 안정성이 유지되는가

가입자 수만으로 판단하지 않습니다. 참여자별 지원·운영 비용도 함께 보아, 사람이 늘수록 유지하기 어려운 서비스가 되지 않게 합니다.

첫 검증과 지금 하지 않는 것

첫 검증 한 지역(예: 홍대·합정 권역)의 연주자와 협력 가능한 공방·악기점에서 '매물 등록 → 검수 → 거래 → 이력 기록'과 '출장 예약 → 수리 → 보증'을 반복합니다. 첫 매물 등록, 첫 거래, 첫 보증 청구까지 현장에서 함께 검증합니다. 현장 도입 지원은 제품의 일부입니다.

지금 하지 않는 것

  • 모든 악기 카테고리의 동시 확장: 기타·베이스·이펙터·앰프부터 시작합니다
  • 자체 결제 엔진, 자체 메신저 엔진, 전용 앱 마켓의 동시 개발
  • 광범위한 물류·보관 창고·자체 보험은 책임과 운영비가 확인된 뒤
  • 채널 자동 등록은 채널별 약관·API 허용 범위를 확인한 뒤, 그 전까지는 반자동
  • 운영사의 직영 매입·판매 확대는 중립 기준이 검증된 뒤
예상 질문
통앤통·뮬 같은 커뮤니티와 무엇이 다른가요?
게시판을 하나 더 만드는 것이 아닙니다. 그 게시판들의 매물을 한 화면에 모으고, 한 번 등록으로 모든 곳에 올리며, 검수·보증·안전결제·이력을 붙입니다. 기존 커뮤니티는 계속 쓰고, 거래의 신뢰 층을 더합니다.
당근마켓·번개장터 같은 중고 앱과는요?
범용 중고 앱은 기타의 넥 상태·전장·수리 이력을 검수하지 않습니다. 우리는 인증 리페어맨의 검수서와 수리 보증, 장비 이력부로 '이 기타가 어떤 상태인지'를 거래의 일부로 만듭니다.
다른 채널의 글을 가져와도 되나요?
각 채널의 공개 매물 정보를 검색 결과로 보여 주고 원문으로 보냅니다. 판매자가 원하면 제외하고, 채널별 약관과 API 허용 범위를 따릅니다. 허용되지 않는 채널은 자동이 아니라 반자동으로 처리합니다.
샵이 왜 들어오나요? 오래된 상권은 자기들끼리 잘 돌아가는데요.
억지로 열지 않습니다. 연주자와 거래가 먼저 모이면, 밖에 있는 비용이 안에 있는 비용보다 커집니다. 간판·가격·거래처 선택권은 그대로이고, 수수료는 이용한 거래에만 붙으며, 언제든 기록을 들고 나갈 수 있기 때문에 들어오는 결정이 가볍습니다.
리페어맨은 어떻게 인증하고, 보증은 누가 책임지나요?
자격·작업 기록·거래 완료 고객의 평가로 인증하고, 기준에 못 미치면 거둡니다. 보증 기간 안의 재발은 플랫폼이 공개된 기준으로 재수리·환불을 처리하고, 작업 기록을 근거로 리페어맨과 정산합니다.
무료로도 쓸 수 있나요? 멤버십은 무엇이 다른가요?
통합 검색·장비 이력부·매물 등록·리페어 예약은 무료입니다. 멤버십은 라운지, 무료 출장 리페어, 검수·위탁 수수료 할인, 우선 예약 같은 추가 서비스입니다. 무료 이용자를 검색에서 뒤로 미루지 않습니다.
플랫폼이 커지면 개인과 샵이 손해 보지 않나요?
노출은 동등하게, 수수료는 성사된 거래에만, 이력·평가·거래 기록은 본인 소유로 두고 언제든 내려받을 수 있게 합니다. 커지는 플랫폼이 개인의 몫을 줄이기 시작하면 사람이 떠나고, 사람이 떠나면 이 사업은 끝납니다.
생태계가 실제로 만들어지고 있는지 어떻게 판단하나요?
제품 개수나 가입자 수가 아니라 위의 여덟 가지 기준으로 봅니다. 특히 샵이 먼저 참여를 요청하는지, 새 서비스를 더했을 때 재등록·재입력이 줄었는지를 가장 먼저 봅니다.
