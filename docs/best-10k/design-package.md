# BEST 생태계 사이트 · 디자인 패키지

10K Websites 스킬의 디자인 패키지 템플릿(`.claude/skills/10k-websites/references/design-package.md`)을 그대로 따른 문서입니다. 생성 전에 쓰고, Phase 8 빌드가 이 문서를 그대로 소비합니다. 여기 적힌 카피는 한 글자도 바꾸지 않고 사이트에 들어갑니다. 밴드 범위와 간격 수치는 출발점이며 플릭 테스트가 확정합니다.

- 사이트 폴더: `sites/best/` (`index.html` + `assets/`)
- 검토·원본 폴더: `sites/best-review/` (커밋되지 않음)
- 티어: Tier 1, 6초 단일 샷, 히어로 높이 500vh (스크롤 범위 400vh)
- 보는 사람: 투자자·파트너. 단일 CTA = 투자·파트너십 문의(`#contact`)
- 분기: 실제 사업, 사진 없음, 시각물 전부 생성, 푸터에 생성 이미지 표기

## 1. 브랜드 프리미스

**레일.** 이 회사는 기능을 파는 회사가 아니라 사람을 잇는 철도를 까는 회사다. 산업혁명기에 철도가 먼저 깔린 곳에 시장이 열렸듯, 기능 제작 비용이 내려가는 AI 이후를 대비해 연결의 기반을 먼저 깐다. 페이지의 모든 섹션은 레일 위의 역이고, 시그니처 요소는 페이지 전체를 관통하는 레일 한 줄이다. 여는 문장과 닫는 문장은 의도된 브랜드 장치로 고정한다.

- 여는 문장(고정): **"기능을 팔지 않습니다. 사람을 잇는 철도를 깝니다."**
- 닫는 문장(고정): **"결국, 사람과 사람을 연결하는 것은 사람입니다."**

이 두 문장은 "X가 아니라 Y" 구문과 큰 마무리 문장에 해당하지만, 브리프가 그대로 쓰라고 한 의도된 장치다. Phase 9 카피 스윕은 이 둘을 건드리지 않는다.

**10k 기본값에서 벗어나는 점(밝힘).** 근흑 캔버스 + 앰버 강조는 10k가 기본 선택으로는 금지하는 룩이다. 이번에는 사용자의 명시된 브리프이자 "레일 불빛"이라는 브랜드 세계의 재료라서 쓴다. 조건: 순흑·순백 캔버스를 쓰지 않고 안개 톤으로 틴트한다, 고대비 세리프와 묶지 않는다, 영상 승인 뒤 실제 프레임에서 톤을 샘플링해 토큰을 확정한다. 현재 사이트의 흑/백 교차 막 구성은 버리고, 10k의 '고정 배경 환경 한 층' 규칙대로 어두운 안개 환경 하나로 간다.

## 2. 팔레트 토큰(출발점, 영상 게이트 뒤 확정)

```css
:root{
  --canvas:#0E0F12;          /* 안개 쪽으로 틴트한 근흑. 순흑 금지. 영상에서 재샘플링 */
  --panel:#171920;           /* 카드·올라온 면 */
  --panel-2:#1F2229;         /* 입력창·강조 면 */
  --accent:#D9AD64;          /* CTA, 강조어 두 곳, 레일 불빛 */
  --accent-hover:#E6BF7C;
  --accent-muted:rgba(217,173,100,.18);   /* 테두리·글로우·입자 */
  --text-primary:#F4F2EC;
  --text-secondary:rgba(244,242,236,.70);
  --text-tertiary:rgba(244,242,236,.48);
  --hair:rgba(244,242,236,.12);
  --hair-strong:rgba(244,242,236,.26);
  --rail-consumer:#D4796B;   /* 노선도 SVG 전용 */
  --rail-business:#D9AD64;   /* 노선도 SVG 전용 */
  --rail-work:#6FAE8A;       /* 노선도 SVG 전용 */
  --rail-hub:#7A9FD6;        /* 노선도 환승역 링 전용 */
  --tshadow:0 1px 2px rgba(5,5,10,.95),0 3px 12px rgba(5,5,10,.78),0 10px 44px rgba(5,5,10,.8);
}
```

대비 목표: 본문 4.5:1 이상, 큰 글자·테두리 3:1 이상. 앰버 `#D9AD64`는 `--canvas` 위에서 약 9.6:1. 노선 3색은 노선도와 로드맵 레일 SVG 안에서만 쓴다.

## 4. 히어로 구성과 밴드 맵

**영상 구도.** 카메라 고정, 약간 높은 시점에서 밤안개 낀 평원. 앰버 빛 레일 한 줄이 화면 오른쪽 3분의 1 구역을 따라 위(먼 지평선)에서 아래(카메라 쪽)로 깔린다. 레일이 지나는 자리마다 멀리 작은 마을 불빛이 하나씩 켜진다. 왼쪽 3분의 2는 안개가 깊이감을 갖고 물러나는 고요한 면으로, 캡션 자리다. 최종 프레임: 레일이 오른쪽 아래에 안착, 불빛들이 아래쪽 3분의 1에 흩어져 숨 쉬고, 왼쪽 위 3분의 2는 깊은 안개 여백.

**캡션 자리.** 밴드 1~3은 왼쪽 열(폭 최대 34ch, 세로 중앙보다 약간 위). 안착 밴드 4는 왼쪽 위에서 시작해 중앙 쪽으로 넓어지는 블록. 레일 레인(오른쪽 3분의 1)은 비워 둔다.

| 밴드 | 범위(출발점) | 영상 순간 | 카피(그대로) | 엔트런스 |
|---|---|---|---|---|
| 1 | 0.00 ~ 0.24 | 지평선에서 레일이 켜지며 출발 | "기능을 팔지 않습니다." / "사람을 잇는 철도를 깝니다." (철도에 앰버 강조) | 안개 걷힘(블러에서 선명으로) + 로드 시 1회 시간 램프 |
| 2 | 0.27 ~ 0.50 | 레일이 중간까지 깔리고 첫 불빛들이 켜짐 | "레일이 먼저 깔린 곳에" / "시장이 열렸습니다." | 내려앉기(단어가 위에서 내려와 자리 잡음, 레일의 하강을 따라) |
| 3 | 0.53 ~ 0.76 | 불빛이 잇달아 켜짐 | "동네 마트, 야채가게, 나들가게." / "자기 이름을 지킨 채 올라탑니다." | 점등(글자가 불빛 켜지듯 순서대로 밝아지며 앰버 글로우가 잠깐 스치고 사라짐; 이 영상을 위해 새로 만든 엔트런스) |
| 4 (안착) | 0.80 ~ 1.00 | 레일 안착, 불빛이 숨 쉼 | 제목 "서비스는 나누고," / "기반은 함께 씁니다." · 보조문 "거래망, 고객 접점, 업무 도구, AI를 하나의 레일 위에서." · CTA "투자·파트너십 문의" · 보조 링크 "노선도 보기" | 단어별 상승 후 단계적 안착(제목 → 보조문 → CTA) |

- 램프는 진행 단위로 `min(0.02, (b-a)/3)`, 첫 밴드는 들어오는 이즈 생략, 마지막 밴드는 나가는 이즈 생략.
- 스크림 피크 알파 출발점: 밴드 1 0.70, 밴드 2·3 0.64, 밴드 4 0.66. 왼쪽 열에 앵커한 타원 스크림, 레일 레인은 밝게 둔다.
- 밴드 3 '점등'은 transform·opacity만 쓴다. 글로우는 가상 요소의 opacity로 낸다.

## 6. 섹션 개요(안착 아래, 순서대로, 카피 그대로)

상단바: 브랜드 마크(세로 막대 3개, 가운데가 더 긺) + "BEST 생태계" · 메뉴 "왜 지금 · 노선도 · 역할 · 업무 · 신뢰 · 수익 · 시작 · 로드맵 · 질문" · CTA "문의". 건너뛰기 링크 "본문으로 건너뛰기".

### 6.1 왜 지금 `#why`
- 키커: 왜 지금
- 제목: "기능을 만드는 비용은 내려갑니다. 남는 것은 연결입니다."
- 보조문: "산업혁명의 가치는 기차표 한 장이 아니라 철도가 이어 준 도시와 사람의 이동에서 나왔습니다. 레일이 먼저 깔린 곳에 시장이 열렸습니다. AI 이후에도 같습니다."
- 시각물: 개념도 SVG(기능 제작 비용 곡선은 내려가고 연결의 가치 곡선은 올라감, 스크롤에 맞춰 스스로 그어짐). 축 라벨 "기능을 만드는 비용", "연결의 가치", "지금".
- 지금 동네 가게의 하루(4줄, 헤어라인 목록):
  - "거래망. 공급사·주변 점포와의 거래가 전화, 메신저, 수기 장부에 흩어져 있습니다."
  - "고객 접점. 온라인으로 팔려면 간판을 바꾸거나 POS를 교체하거나 외부 플랫폼의 조건을 따라야 합니다."
  - "업무 도구. 발주, 재고, 근태, 승인이 대화와 따로 놉니다. 지금 쓰는 메신저에는 말만 남습니다."
  - "AI. 자료가 흩어져 있어 AI가 도울 근거가 없습니다. 쌓이는 건 대화뿐, 판단의 기록이 아닙니다."
- 세 줄:
  - "레일을 먼저 깝니다." "계정, 상품 기준, 파일, 메신저, 승인 같은 공통 기반을 먼저 만들고, 서비스는 그 위에 올라탑니다."
  - "역을 하나씩 늘립니다." "사진 한 장으로 시작하는 야채가게부터 부서별 승인이 필요한 중형 마트까지, 필요한 기능 하나로 올라탑니다."
  - "사람이 사람을 연결합니다." "우리는 마트를 직접 운영하며 그 현장을 출발점으로 삼습니다. 기능은 복제되지만 신뢰로 쌓인 관계망은 복제되지 않습니다."
- 레이아웃: 왼쪽 글, 오른쪽 개념도(분할). 인접 섹션과 골격이 겹치지 않게 다음 섹션은 중앙 정렬 전폭.

### 6.2 생태계 노선도 `#map`
- 키커: 생태계
- 제목: "서비스는 나누고, 기반은 함께 씁니다."
- 보조문: "브랜드, 고객, 거래 방식은 서비스마다 다르게. 계정, 상품정보, 메신저, 업무 연결은 하나로. 새 서비스는 복제가 아니라 이 노선도의 역으로 추가됩니다."
- 시각물: 노선도 SVG(직접 그림). 소비자선(베스트마켓 직영몰, 베스트마트 온라인몰), 사업자선(베스트마켓 운영허브), 업무선(ERP, 메신저, ARGOS), 중앙 환승역 "공통 기반". 스크롤에 맞춰 선이 그어지고 역이 순서대로 나타남. 720px 미만에서는 가로 스크롤.
- 노선 설명(3줄 + 환승역):
  - "소비자선. 베스트마켓 직영몰. 개인 고객과 본사 직영 판매. 본사가 상품 구성, 판매가격, 주문, 고객 응대를 독립적으로 책임집니다."
  - "소비자선. 베스트마트 온라인몰(협력사몰). 개인 고객과 기존 마트·협력사. 매장별 상품, 가격, 수량, 배송·픽업 조건. 간판과 POS를 바꾸지 않고 참여합니다."
  - "사업자선. 베스트마켓 운영허브(가칭). 점주·판매점과 다른 점주·공급사. 상품자료 공유, 공급 제안, 구매 요청, 공동구매. 반무인 픽업전문점도 참여합니다."
  - "공통 기반. 계정, 사업자, 점포, 상품 기준, 파일, 거래 연결, 재고 연동, 배송·픽업, 권한, 알림, 감사기록. 하나의 로그인으로 들어오지만, 어떤 회사·점포의 자료를 볼 수 있는지는 요청마다 따로 검사합니다."

### 6.3 하나의 마트, 네 가지 역할 `#roles`
- 키커: 서비스
- 제목: "하나의 마트가 네 가지 역할을 가집니다."
- 보조문: "마트를 네 번 등록하지 않습니다. 하나의 사업자, 하나의 점포에 참여 역할과 연결된 서비스를 더합니다."
- 시각물: 중앙 "우리동네마트 · 하나의 사업자 · 하나의 점포" 노드에서 네 방향으로 뻗는 선(스스로 그어짐). 네 역할 카드(동일 취급):
  - "판매자" "내 온라인몰에서 소비자에게 판매" "베스트마트 온라인몰"
  - "구매자" "운영허브에서 공급사 상품 구매" "베스트마켓 운영허브"
  - "공급자" "남는 물량을 다른 점포에 판매" "베스트마켓 운영허브"
  - "수령대행자" "직영몰 주문 물품을 보관하고 전달" "베스트마켓 직영몰"

### 6.4 대화가 곧 업무 `#work` (인터랙티브 모먼트가 사는 섹션)
- 키커: 업무 도구
- 제목: "대화가 곧 업무가 됩니다."
- 보조문: "조회, 요청, 승인, 실행, 결과 확인까지 한 대화에서. ERP에서 열든 ARGOS에서 열든 같은 대화, 같은 승인함입니다."
- 도구 3행:
  - "ERP" "실제 업무 기록과 처리. 거래 상대와 연결돼도 각 회사의 기록은 각자의 ERP에 남습니다."
  - "메신저" "사람이 쓰는 공통 창구. 대화는 그냥 쌓이지 않고 발주, 입고, 재고, 근태 기록과 연결됩니다."
  - "ARGOS" "서비스와 AI 에이전트의 조정. 허용된 범위에서 상태를 모으고, 확인할 사항을 제안하며, 승인된 실행을 연결합니다."
