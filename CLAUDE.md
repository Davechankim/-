# Project guidance

This is the BEST ecosystem investor website, built with plain HTML, CSS and JavaScript.
Read `DESIGN.md` before visual changes. Preserve the existing typography, color tokens,
accessibility behavior and reduced-motion support unless the user requests a redesign.
Do not introduce React or Motion solely because a toolbox module mentions them.

The project skill is `.claude/skills/design-toolbox/SKILL.md`, invoked with
`/design-toolbox`. Load only the guides relevant to the request; `registry.json`
indexes the complete bundled collection. Listing modes alone does not authorize site edits.

Cloud setup and MCP troubleshooting are in `docs/design-toolbox-cloud.md`.
The skill and its 326 guides work without external accounts. A configured MCP server
is not proof of authentication: check actual tools before claiming a connection.
Never commit personal API keys, OAuth tokens, local settings or browser sessions.
